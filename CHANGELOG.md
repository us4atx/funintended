# FunIntended releases

Bump `apps/backend/api/version.mjs` with every change to the client sites, and add a line here.
Each version is rolled out to client sites one by one from the backend (Admin panel → Releases).

## 1.1.0 — 2026-11-28
- Hosting on our own VPS (no Netlify). New clients get their two sites set up automatically.
- Versioned releases with site-by-site rollout and rollback from the backend.

## 1.0.0 — 2026-11-25
- First version running on the VPS (demo + beta1 sites).
